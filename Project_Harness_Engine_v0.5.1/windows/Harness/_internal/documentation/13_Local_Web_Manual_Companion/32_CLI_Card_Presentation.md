# Рабочая область и состояние подключения CLI

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-10

По заданию пользователя рабочая область вкладки «Опрос и GPT» занимает всю доступную ширину страницы с сохранением навигации и обычных отступов. Ограничения ширины других разделов не меняются. Два способа анализа остаются рядом, с переходом в одну колонку на узком экране по главе 31.

В карточке Codex CLI кнопки находятся в одной строке. Основное действие называется «Анализировать через CLI». После подключения первая кнопка показывает «Подключено» и зелёную галочку; инструкция по подключению скрывается. Кнопка остаётся доступна для повторной проверки подключения, кроме времени запроса или активного анализа. Если повторная проверка не удалась, снова доступны подпись «Подключить CLI» и инструкция. Обновление страницы восстанавливает представление из существующего состояния приложения.

Пустая стартовая подсказка «После запуска результат анализа появится здесь, без скачивания пакета и копирования JSON.» удалена. Реальные сообщения о ходе анализа, результате и ошибках продолжают отображаться. Внизу карточки мелким серым шрифтом указано: «На выполнение расходуются токены агента.»

Изменено только представление HTML/CSS/JS и build metadata. Подключение и запуск CLI, существующие ограничения, пакеты и preview, API, schemas/registries и core не меняются. Local login и дополнительные подтверждения не добавляются.

Целевая проверка ограничена шириной, расположением кнопок, подписями и состояниями карточки до/после подключения, reload и ошибки повторного подключения. Используются настоящий TCP/headless Edge и явно обозначенный CLI connection fixture; реальный анализ модели для этой правки не запускается. Проверки всего движка, full core regression и вся PH-LW matrix не выполняются. Прежние exact-byte verdicts не переписываются; automatic Task executor остаётся выключен, полная v0.5.1 NOT RELEASED.
