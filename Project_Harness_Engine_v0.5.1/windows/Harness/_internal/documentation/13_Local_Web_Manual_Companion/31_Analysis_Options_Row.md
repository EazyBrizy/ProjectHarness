# Способы анализа рядом в одной строке

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-10

По заданию пользователя в блоке «1. Выберите способ анализа документов» карточки «Автоматически через Codex CLI» и «Вручную через ChatGPT или Codex» размещены рядом в двух равных колонках. Общий заголовок находится над ними. На экранах шириной 760 CSS pixels и меньше карточки располагаются друг под другом для читаемости. Текст и кнопки переносятся внутри карточки, горизонтальная прокрутка не требуется.

Изменены только HTML/CSS размещения блока и идентификатор сборки. Порядок работы из главы 30, содержимое пакетов, подключение CLI, анализ, ответы модели, API и проектные данные не меняются. Не добавляются local login, подтверждения и выбор категорий документов.

Достаточная проверка этой правки — отображение блока в настоящем headless Edge на широком, промежуточном и узком экране, затем целостность изменённой поставки и зеркал документации. Повторный запуск анализа модели, full engine/core regression и PH-LW matrix не требуется и не выполняется. Исторические verdicts сохраняют свои exact-byte границы; automatic Task executor остаётся выключенным, полная v0.5.1 NOT RELEASED.
