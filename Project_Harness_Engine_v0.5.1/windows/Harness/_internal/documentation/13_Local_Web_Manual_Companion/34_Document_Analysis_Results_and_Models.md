# Понятный результат анализа и выбор модели CLI

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-12

Дополнение по заданию пользователя от 2026-11-12. Применяется к анализу
документации; не включает автоматическое выполнение задач создаваемого проекта.

После загрузки ZIP откройте «Опрос и GPT». Есть два равноправных пути:

1. Подключите CLI, выберите модель и глубину рассуждения, нажмите «Анализировать
   через CLI». Выбор сохраняется автоматически; в результате запуска показаны
   именно параметры этого запуска, даже если настройки затем изменены.
2. Нажмите «Сформировать пакет вручную». Скачанный ZIP содержит инструкцию и
   полный pack.md. Передайте его ChatGPT/Codex, затем вставьте JSON через
   «Вставить ответ при ручном обмене» на шаге 2.

Результат показывает суть проекта, ближайший рекомендуемый этап, содержательные
ответы с источниками, последовательность работ и критерии готовности. Для
предложений/гипотез и противоречий есть отдельные подписи. Будущие этапы и их
вопросы свёрнуты отдельно; они не становятся текущими blockers. Обзор плана из
источников не является утверждённым executable Stage/Task/JIT планом Harness.
Версия технологии, масштаб и цена не выдумываются, если их нет в документах.

До «Сохранить предложения» результат — PREVIEW. Старый незаполненный опрос
временно скрыт, чтобы его не путали с уже извлечёнными ответами. После сохранения
показаны оставшиеся вопросы: полный текст, причина и основание. Ответ можно
сохранить и отметить вопрос решённым одним действием. Редактирование объектов
сохраняет их структуру (например, имя пользователя и его задачу). Согласования
остаются отдельными решениями; повторных подтверждающих dialogs/галочек нет.

## Формат и обработка

Прямой анализ/ручной ZIP используют LOCAL_WEB_GPT_DRAFT_ONLY@3. Новая локальная
schema добавляет analysis (summary/current_stage/answers/roadmap/notes) и один
канал questions с устойчивым id темы, field, question, why, stage,
blocking и source_refs. project.unknowns модель копирует из пакета; сервер
переносит новые вопросы сам. Один id/нормализованный текст объединяется один раз,
противоречивые этап/обязательность отклоняются. Комментарии не становятся
вопросами; FUTURE + blocking=true запрещены. Исходные пользовательские unknowns
не удаляются моделью. Ответы на них разрешает явное редактирование пользователя.

Analysis и claims сохраняются с digest записи импорта. Exact export/source/input
bindings, strict PROJECT_INPUT@4 validation, protected fields, revision/replay
checks, отсутствие approvals/автосохранения остаются. Core schemas/registries
не изменены. Старые v2 пакеты и записи читаются; принятая история не переписывается.
Для старого анализа интерфейс предлагает повторный разбор новым форматом.
После изменения источников прежний обзор помечается требующим пересмотра.

## Параметры модели

Явное подключение CLI получает его каталог командой `codex debug models`
(experimental в CLI 0.154.0). В UI выводятся видимые модели и поддерживаемые
уровни рассуждения; значения проверяются по локальному cache. GET ничего не
запускает. POST `/api/cli/model` сохраняет выбор, не запускает анализ и не
принимает произвольные команды/пути. Обновление CLI требует переподключения.
Если каталог получить нельзя, показана ошибка и доступен ручной путь.

Каждый job фиксирует запрошенные model/reasoning_effort. Invocation явно передаёт
`--model` и `-c model_reasoning_effort=...`; пользовательский config по-прежнему
игнорируется. Внутреннее разрешение серверных aliases не заявляется измеренным.
У старых jobs модель честно обозначена как не сохранённая. Настройка не означает
гарантию доступа аккаунта к модели; отказ CLI показывается как ошибка запуска,
скрытого переключения на другую модель приложение не выполняет.

Фиксированные read-only sandbox, выключенные command/app/plugin/web tools,
лимиты процесса, cancel только своего процесса, strict preview и отсутствие
Task/product writes сохранены. На анализ расходуются токены агента.

Параметры сверены с [официальной CLI reference](https://learn.chatgpt.com/docs/cli/reference)
и установленным native CLI. Проверяются только изменённые сценарии согласно
[целевому объёму проверок](27_Targeted_Verification.md); полный движок и вся
PH-LW matrix не являются обязательной повторной проверкой этой правки.
