# Активные кнопки и обязательные поля документов

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-09

Во вкладке «Документы» кнопки создания проекта, импорта, выбора «Документации нет» и перехода к опросу доступны для нажатия даже при незаполненной форме. Недостающие обязательные условия проверяются при нажатии. Красное сообщение объясняет следующий шаг; фокус переводится на нужное поле или кнопку. Невалидный ввод не отправляет mutation в Engine.

- Нет названия: введите название проекта.
- Название есть, но проект ещё не создан: нажмите «Создать проект для документов» и повторите действие. Само заполнение имени или выбор ZIP не создаёт intake.
- Проект создан, файлы не выбраны: выберите ZIP с Markdown либо файлы MD.
- Выбраны, но ещё не импортированы новые файлы: нажмите «Импортировать файлы» и дождитесь результата.
- Для перехода к опросу нет сохранённых MD и не подтверждено отсутствие документации: импортируйте документы либо явно выберите «Документации нет».
- Выбран опубликованный Project Instance: заменять его источники здесь нельзя; форма сообщает о поддержанном выборе нового проекта/существующего черновика.
- Не прочитан текущий source inventory: нажмите «Обновить состояние»; устаревший snapshot другого проекта не используется.

На время выполняющегося запроса кнопки временно отключаются, чтобы исключить двойное нажатие. После завершения запроса они снова доступны, включая случаи отказа. При исправлении ввода сообщение и `aria-invalid` очищаются.

Это заменяет только правила доступности кнопок из [главы 24](24_Document_Upload_Feedback.md). Сохранение источников, confirmations, current fingerprint/source revision, отдельные approvals и canonical states не менялись. Активная кнопка не означает выполнение недопустимой операции: frontend объясняет препятствие, а public service сохраняет независимую проверку. Automatic executor disabled.
