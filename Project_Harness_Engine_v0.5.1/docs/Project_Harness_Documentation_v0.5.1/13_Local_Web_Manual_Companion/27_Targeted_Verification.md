# Проверяем только изменённую функциональность

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-09

## Обязательное рабочее правило

По прямому указанию пользователя от 2026-11-09 после локальных изменений проверяем только то, что меняем, и доказанные прямые зависимости изменения. Весь движок раз за разом не проверяем.

Перед запуском tests обозначить изменённое поведение и выбрать минимальный достаточный набор проверок для него. Для небольшой правки формы проверять её поведение, сообщения и затронутый запрос. Если меняется общий launcher или HTTP contract, добавить конкретные проверки этих изменённых путей. Это не основание запускать все бизнес-сценарии движка.

Полный core regression, весь набор модулей или полная PH-LW matrix запускаются только по отдельному явному запросу пользователя. Наличие исторического требования полного прогона в плане, prompt, runbook или отчёте не разрешает такой прогон при каждой правке.

Прошедшие проверки не повторять без новых изменений в проверяемой области, воспроизводимого сбоя либо другой конкретной причины. При изменении упаковки проверять соответствующий артефакт; это не требует повторять все проверки поведения продукта.

## Фиксация результата

В отчёте указывать фактически выполненные целевые проверки и их результат. Не называть их полной приёмкой движка. Не назначать проверки посторонних модулей обязательными blockers небольшой правки и не расширять задачу на их исправление без отдельного запроса.

Сохранять исходные expectations и raw logs. Семантические failures нельзя устранять ослаблением проверок. Документационные mirrors/manifests и целостность обновлённой поставки поддерживать; для docs-only изменений проверки кода не нужны.

## Приоритет

Это указание заменяет прежние требования повторных широких прогонов в рабочих инструкциях и сохранённых планах. Исторические specs, prompts и отчёты сохраняются неизменными. Правило продублировано в корневом AGENTS.md, CURRENT_TASK.md и RUNBOOK.md, чтобы оно применялось и в следующих задачах.
