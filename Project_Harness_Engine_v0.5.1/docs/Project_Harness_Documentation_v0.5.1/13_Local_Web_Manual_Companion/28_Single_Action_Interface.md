# Действия без повторных подтверждений

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-09

## Обязательное решение пользователя

По прямому указанию пользователя во всём интерфейсе нет всплывающих подтверждений «OK / Отмена» и дополнительных обязательных галочек «подтверждаю / разрешаю / я прочитал». Нажатия кнопки выбранного действия достаточно. Не возвращать такие дополнительные шаги при следующих правках.

Это относится к созданию проекта, загрузке и замене документов, ответу «Документации нет», остановке Harness, экспорту пакета, применению решений, размещению проекта, проверке Task, сохранению наблюдений и действиям жизненного цикла. В CLI команда записи manual evidence и команда verify также не требуют дополнительного флага-подтверждения.

Обычный порядок: заполнить необходимые данные → нажать кнопку действия → увидеть результат или понятную ошибку в той же форме. Отдельный native confirm dialog и дополнительный checkbox не появляются. В форме размещения достаточно имени папки и кнопки; в форме проверки достаточно самой кнопки «Проверить» для показанного плана.

## Граница изменения

Нажатие конкретной кнопки либо явная CLI-команда являются самостоятельным намерением выполнить это действие. Существующие API-поля `confirm`, `confirmed`, `consent` заполняются адаптером этого нажатия без второго вопроса пользователю. Они не требуют отдельного элемента интерфейса.

Загрузка страницы, чтение статуса и polling по-прежнему не запускают изменений. Содержание документов/GPT не исполняется. Проверки формата, обязательных данных, актуального проекта/Run/плана и revision/replay остаются в ядре. Решения записываются только действием пользователя, по текущему содержанию; автоматического принятия решений при загрузке страницы или импорте нет.

Исторические описания checkbox/dialog flow сохраняются как история, но для текущего UI это решение имеет приоритет. Проверяются только изменённые обработчики, наличие inline errors и отсутствие повторных подтверждений; полный прогон движка не выполняется.
