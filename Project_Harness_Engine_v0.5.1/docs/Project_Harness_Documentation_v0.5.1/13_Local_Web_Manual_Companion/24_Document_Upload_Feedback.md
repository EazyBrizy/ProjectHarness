# Загрузка документации: выбор, импорт и следующий шаг

**Версия:** 0.5.1-WIP / NOT RELEASED  
**Дата:** 2026-10-25 (база документации v0.5.1)  
**Дата дополнения:** 2026-11-09

## Порядок действий

1. Откройте **«Документы»**. Для нового проекта введите название и нажмите **«Создать проект для документов»**. Существующую подготовительную рабочую область можно выбрать во вкладке **«Проекты»**. Опубликованный Project Instance здесь не принимает замену источников.
2. Выберите ZIP с Markdown или один/несколько MD. Сам выбор файла ещё не запускает загрузку. Файлы можно выбрать и до создания проекта: форма объяснит, какой шаг требуется, и сохранит выбор до импорта.
3. Нажмите **«Импортировать файлы»** и подтвердите действие. Прогресс показывает передачу байтов. Затем форма сообщает **«Файлы переданы. Проверяем архив и документы…»**: сервер ещё проверяет содержимое, завершение передачи не считается успехом.
4. После ответа сервера появится **«Документы загружены: N MD»**, числа принятых/пропущенных/отклонённых документов, ревизия и список источников. Неподдержанные вложения перечислены с причинами. Импорт не выполняет смысловой GPT-анализ и не заменяет отдельные formal approvals.
5. Нажмите **«Перейти к опросу и GPT →»**. Кнопка открывает существующую форму опроса. Она не подтверждает содержание документов, не выдаёт approval и не запускает исполнение проекта.

При осознанном выборе **«Документации нет»** форма показывает подтверждение и также разрешает переход к опросу. Если выбраны новые файлы, сначала необходимо закончить их импорт или очистить выбор; старый успешный импорт не выдаётся за результат для новых файлов.

## Отказы и повторное открытие

Опасный ZIP отклоняется существующим importer целиком. Форма показывает отказ; повторный запрос требует отдельного действия оператора. Ранее сохранённые источники остаются в списке. Побайтово повторный импорт сообщает, что файлы уже загружены, без новой ревизии или копий.

При сбое соединения результат считается неизвестным: сервер мог сохранить импорт до потери ответа. Нажмите **«Обновить»** или перезагрузите страницу и проверьте список/ревизию перед повторной отправкой. POST автоматически не повторяется. После повторного открытия успешный статус и возможность продолжить выводятся из read-only source inventory, а не из несохранённого сообщения браузера.

## Граница исправления

Изменены только подсказки, доступность элементов и отображение существующего source inventory. Public Engine APIs, exact revision/fingerprint checks, source validation, безопасность HTTP, отдельные approvals и canonical states сохраняются. Automatic executor выключен.
