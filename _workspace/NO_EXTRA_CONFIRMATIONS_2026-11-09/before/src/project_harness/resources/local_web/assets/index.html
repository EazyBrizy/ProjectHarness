Доступные действия

              
Каждое изменение требует отдельного подтверждения, точного fingerprint и защищённого POST.

              

              

              
              
В текущем интерфейсе можно просмотреть результат своей операции. Экспорт общего журнала не реализован.

            

          

        

      

      

        
Документы и источники

        
Только локальные MD (UTF-8) и ZIP с MD. Импорт не анализирует документы и не отправляет их в интернет.

        

        

          

            
1. Создайте или выберите проект

            
Для нового проекта введите название и нажмите «Создать проект для документов». Если проект уже есть, выберите его во вкладке «Проекты».

            
            
            

              
              
            

            
            
            
Системное окно выбора папки. Assessment и preparation читают исходный репозиторий; новый Project Instance размещается отдельно.

          

          

            
2. Выберите и импортируйте документы

            
Проект для загрузки ещё не выбран.

            

              
              
              
Файлы не выбраны

            

            
            
            

              
              
              
            

            

              Сначала создайте или выберите проект
              
Затем выберите ZIP с Markdown или файлы MD и нажмите «Импортировать файлы». Выбор файла сам по себе не запускает загрузку.

            

            
            

            
3. Продолжите подготовку проекта

            
          

        

        
Принятые источники и история

        
Выберите intake из списка проектов.

        

        
Предпросмотр как экранированный текст

        
Выберите документ для просмотра.

        
Лимиты: весь запрос с ZIP до 64 MiB; один MD или распакованный элемент до 8 MiB; суммарное распакованное содержимое до 128 MiB; до 1000 элементов; вложенность до 16; сжатие до 200:1. Опасный ZIP отклоняется целиком.
